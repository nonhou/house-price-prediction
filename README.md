# 二手房价格预测

对某城市各区二手房数据完成清洗与特征工程，用线性回归模型预测房源总价，并绘制测试集真实值与预测值对比图。

## 数据

- 来源：某城市二手房房源数据 `data.csv`
- 字段：小区名字、总价、户型、建筑面积、单价、朝向、楼层、装修、区域

> 原始数据未上传，请自备同类房源数据。

## 方法

### 1. 导入数据

加载 `data.csv`，同时导入 `matplotlib`、`numpy`、`pandas` 与 `sklearn` 的相关模块。

### 2. 清洗数据

- 删除索引列 `Unnamed: 0`
- `dropna(axis=0, how='any')` 删除含空值的记录
- `总价` 字段去掉「万」后缀并转为浮点数
- `建筑面积` 字段去掉「平米」后缀并转为浮点数

### 3. 特征工程

- 用正则 `(\d+)室(\d+)厅(\d+)卫` 从 `户型` 字段提取 `室`、`厅`、`卫` 三个数值特征
- 建模特征取 `建筑面积`、`室`、`厅`、`卫`，标签为 `总价`
- 用 `train_test_split` 划分训练集与测试集

### 4. 建模

`sklearn.svm.LinearSVR` 建立回归模型并在训练集上拟合。

### 5. 评估

用 `sklearn.metrics` 的回归指标评估模型表现。

### 6. 可视化

绘制测试集真实值与预测值对比折线图：真实值用圆点标记，预测值用叉号 + 虚线标记，观察两者走势差异与偏离样本。

## 结果

在 0–600 万价位区间上，预测值与真实值整体走势接近，但部分样本（如高价房源）预测偏差较明显。

> 本项目的评估指标数值未在实训报告中留存，因此未在此处填写具体分数。重新运行 `metrics` 评估代码即可得到当前数据下的结果。

